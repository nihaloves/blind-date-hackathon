# 🌕 MOONLOOP: STRANDED

> **Interactive Lunar Survival Simulation & Mission Control Dashboard**

MOONLOOP: STRANDED is a sci-fi survival strategy and resource management simulation where you play the mission commander of a lunar habitat crew awaiting emergency extraction. Balance life-critical resources, manage cascading subsystem failures, respond to unpredictable crises, and consult an on-board AI mission advisor to keep your crew alive.

---

## 🚀 Quick Start

### Option 1: Zero-Dependency Standalone (Instant Play)
Simply open **`moonloop.html`** in any modern web browser (Chrome, Edge, Firefox, Safari).
- No Node.js or `npm` required.
- Everything runs client-side with React loaded via CDN.

### Option 2: Vite Dev Server
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🎮 Key Features

- **Dynamic Resource Simulation**: Real-time modeling of Oxygen, Water, Food, Habitat Pressure, Power Grid, and Crew Vitals.
- **Cascading Subsystem Failures**: Failure in one life-support sector ripples through interdependent systems (e.g., power deficits trigger life-support de-prioritization and O2 drops).
- **Interactive Mission Control UI**:
  - Telemetry meters & status monitors
  - Action cards for habitat maintenance, rationing, and emergency repairs
  - Dynamic event log
  - AI Advisor offering tactical survival recommendations
- **High-Stakes Scenarios**: Solar flares, micrometeorite strikes, seal breaches, and extraction delays.
